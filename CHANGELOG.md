# Changelog

## [0.1.1] - 2026-03-20

Initial release.

### Features

- Bridges VS Code's built-in language intelligence to Claude Code over a local Unix domain socket
- Supports hover, go-to-definition, type definition, implementation, references, completions, document symbols, workspace symbols, rename, and diagnostics
- Language selection setting to choose which installed language servers to expose
- Auto-start option to launch the bridge when VS Code opens
- Generate Local Claude Plugin command to create a ready-to-use plugin directory for Claude Code
